4. Fase 9 — Endurecimiento y despliegue K3s/Kubernetes CERRADA EN GIT

Objetivo: empaquetado OCI inmutable, observabilidad técnica, seguridad de transporte, manifiestos K3s multi-ambiente y CI/CD automatizado vía GitHub Actions.

Cerrada en Git mediante commits locales autorizados: MS.Cobroup.Backend (e02bd65), MS.Cobroup.BackendAdmin (91152b1), MF.cobroup-frontend (c3f007f), MF.cobroup-frontend-admin (d218f03).

Entregables completados

  • Health checks avanzados de base de datos: endpoints /health/live y /health/ready en ambos backend verificando conectividad a PostgreSQL.
  • Seguridad HTTP y Reverse Proxy: configuración de UseForwardedHeaders para soporte de Ingress Traefik y middleware de cabeceras de seguridad (X-Content-Type-Options, X-Frame-Options, Referrer-Policy) y rastreo de trazabilidad con X-Correlation-ID.
  • Contenedores multi-stage no privilegiados: Dockerfiles optimizados para .NET 10 y Nginx 1.27 en puerto 8080 con usuarios sin privilegios (1000:1000 y nginx).
  • Manifiestos K3s / Kubernetes (k8s/): plantillas declarativas para Deployments, Services, ConfigMaps, Secrets e Ingress Traefik con soporte de ambientes dinámicos: cobroup-dev, cobroup-qa, cobroup-prod.
  • Automatización CI/CD con GitHub Actions: flujos .github/workflows/ci-cd.yml en los 4 repositorios que ejecutan pruebas automatizadas, publican imágenes en GitHub Container Registry (GHCR) y despliegan vía SSH en el cluster K3s aplicando variables y secretos de GitHub por ambiente.
  • Servicios PWA: PwaUpdateService y PwaInstallService en ambas PWA para actualización automática e instalación en dispositivos.

5. Validación de cumplimiento de marcos de desarrollo

Auditoría técnica de los cuatro repositorios frente a los estándares canónicos del proyecto:

5.1 Framework C# / Backend (FRAMEWORK_DESARROLLO_CSHARP.md v2.0)

  • Rama autorizada: verificación de rama feature/fase-9-endurecimiento-despliegue en ambos backend.
  • Arquitectura hexagonal: observabilidad implementada en Api/Health sin acoplamiento a la lógica de negocio del dominio.
  • Seguridad perimetral: middleware de seguridad HTTP inyectado en el pipeline ASP.NET Core.
  • Aislamiento multi-tenant: separación estricta en base de datos PostgreSQL y en Kubernetes por namespaces (cobroup-dev, cobroup-qa, cobroup-prod).

5.2 Framework Frontend (FRAMEWORK_DESARROLLO_FRONTEND.md v1.0)

  • Servicios core PWA: PwaUpdateService y PwaInstallService desacoplados en core/pwa.
  • Tokens semánticos de temas: uso exclusivo de variables CSS var(--color-...) en componentes.
  • Presupuestos CSS estrictos: todos los componentes de ambas PWA compilan bajo el límite de 4.00 kB sin advertencias.
  • Pruebas en Vitest: 59 pruebas frontend automatizadas ejecutadas y pasando con --watch=false.
